 # 手作り分光器（光のスペクトル観測器）

手作りの箱と回折格子（グレーチングシート）を使って、光を波長ごとに分けて観察する装置です。

## 1. 用意するもの
- 工作用台紙（ [spectroscope_1000pmm_body_template_095.pdf](spectroscope_1000pmm_body_template_095.pdf)を等倍印刷したもの）
- 厚紙（台紙を貼るか、厚紙に直接印刷）
- レプリカグレーチングシート（1000本/mm）
- ハサミ、カッター、定規
- 両面テープまたはセロハンテープ、黒いビニールテープ（遮光用）

※ グレーチングシートが500本/mmのものを用意した場合は、台紙は[こちら](spectroscope_body_template_095.pdf)です。

## 2. 作り方のポイント
- **スリットは細くまっすぐに**：幅0.5mm〜1mm程度がベストです。
- **シートの向き**：スリットのスジとシートの溝が平行になるように貼り付けます。
- **隙間からの光漏れを防ぐ**：箱の継ぎ目から外の光が入ると見づらいため、黒テープ等でしっかり遮光します。

## 3. 安全上の注意（必ず守ってください）
- **太陽を絶対に直接のぞかないこと**（失明・眼障害の危険）。
- 太陽光を調べる際は、太陽そのものではなく「青空」や「直射日光が当たっている白い紙」を観察してください。

## 4. なぜ光が分かれるの？（科学の仕組み）
- **光は波であること**：波の長さ（波長）によって色（紫〜赤）が違います。
- **回折格子（グレーチング）の働き**：1mmに1000本もの細かな溝があり、光がそこを通ると波同士が強め合う角度（回折）が波長によって異なります。
- その結果、光が色ごとに扇状に分かれて目に入ります。

## 5. いろいろな光をくらべてみよう（観察シート）
| 光源 | 見え方の特徴 | 理由 |
| :--- | :--- | :--- |
| **太陽光（青空）** | 紫〜赤まで切れ目ない虹色（連続スペクトル） | 高温の物体が放つ幅広い波長の光 |
| **蛍光灯** | 明るい線が飛び飛びに見える（輝線スペクトル） | 水銀蒸気が特定の波長の光を出しているため |
| **白色LED** | 強い青色の線 ＋ なだらかな黄色〜赤色 | 青色LED ＋ 黄色蛍光体の組み合わせ |
| **スマホ画面** | 赤・緑・青の3つにハッキリ分かれる | 光の三原色（RGB）の画素 |
